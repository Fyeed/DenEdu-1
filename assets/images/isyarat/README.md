# Foto isyarat

Letakkan foto terverifikasi di folder ini dengan nama `<id-materi>-<bahasa>.jpg`, `.png`, atau `.webp`. Contoh: `b-sibi.jpg`, `bola-bisindo.webp`, atau `sy-ba-sibi.png`. Bahasa menggunakan nama kecil `sibi` atau `bisindo`.

Untuk daftar materi dan ID suku kata, lihat bagian materi di `../../../README.md`. Pastikan izin penggunaan media telah diperoleh dan isi isyarat diperiksa penutur/pengajar bahasa terkait.
