# Video isyarat

Letakkan video terverifikasi di folder ini dengan nama `<id-materi>-<bahasa>.mp4` atau `.webm`. Contoh: `b-sibi.mp4`, `bola-bisindo.webm`, atau `sy-ba-sibi.mp4`. Bahasa menggunakan nama kecil `sibi` atau `bisindo`.

Untuk daftar materi dan ID suku kata, lihat bagian materi di `../../../README.md`. Pastikan izin penggunaan media telah diperoleh dan isi isyarat diperiksa penutur/pengajar bahasa terkait.
